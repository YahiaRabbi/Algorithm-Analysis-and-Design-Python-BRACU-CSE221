A. Odd or Even?

⏱ Time limit 1 second
💾 Memory limit 256 megabytes
Forbidden Keywords for the Quiz: sort, open, file, creat(, fstream, thread, process, system(, exec(

Do you know how to tell if a number is Odd or Even? You are given T numbers, and for each of those numbers, you have to tell whether the number is odd or even.

Input

The first line will contain a single integer T (1 ≤ T ≤ 100). Each of the next T lines will contain a number N (−105 ≤ N ≤ 105).

Output

For each N, you have to print whether the number is odd or even. See the sample input-output format to know what exactly you have to print.

Example
input
5 10 19 7 3 100
output
10 is an Even number. 19 is an Odd number. 7 is an Odd number. 3 is an Odd number. 100 is an Even number.
